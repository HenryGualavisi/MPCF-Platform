# MPCF Platform by TRAZIX HG — Demo V0.2

Prototipo funcional de captura, almacenamiento local, movimientos y trazabilidad.

## Branding
La interfaz utiliza el branding de MPCF Platform by TRAZIX HG proporcionado para el proyecto.

## Funcionalidades
- Crear lote agrícola.
- Registrar cosecha.
- Crear recepción de materia prima.
- Generar disponibilidad en Bodega MP.
- Consumir materia prima para una producción.
- Crear producción y generar identificador compuesto fecha + turno + COD.
- Consultar productos / ISOL.
- Reportar flujo de materiales.
