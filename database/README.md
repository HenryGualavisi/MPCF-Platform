# Base de datos MPCF

Este directorio contendrá todo lo relacionado con el modelo de datos y la evolución de PostgreSQL/Supabase.

## Propósito

- centralizar el conocimiento del esquema y su evolución
- documentar entidades, relaciones y eventos del dominio
- preparar la base para futuras migraciones oficiales
- mantener una referencia clara para desarrollo y auditoría

## Contenidos esperados

- definiciones del modelo de datos
- relaciones y reglas de negocio críticas
- modelo de trazabilidad y evidencias
- documentación de integridad y seguridad
- referencia a migraciones versionadas

## Regla importante

Las migraciones oficiales de PostgreSQL/Supabase son la fuente autorizada para evolucionar el esquema.
