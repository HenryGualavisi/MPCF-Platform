# Documentación MPCF

Este directorio contendrá la documentación funcional, de negocio, arquitectónica, de seguridad, de trazabilidad y de decisiones del proyecto.

## Propósito

- documentar el modelo operativo de TRAZIX HG
- registrar decisiones de arquitectura y negocio
- describir requisitos funcionales y reglas de trazabilidad
- mantener la evidencia documental y la historia del sistema
- servir de referencia para agentes, desarrolladores y revisores

## Contenidos esperados

- documentación funcional
- reglas del dominio industrial
- arquitectura general del sistema
- seguridad y permisos
- trazabilidad y evidencias
- decisiones relevantes y convenciones del proyecto
